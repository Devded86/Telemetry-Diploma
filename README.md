Програмно-апаратний комплекс SCADA для Industry 4.0

Дипломний проєкт бакалавра комп'ютерної інженерії (НТУУ "КПІ" Ім. Ігоря Сікорського, група КВ-22).

## Основний функціонал:
* Двоканальний моніторинг телеметрії лінії (вага продукту та металодетекція).
* Термометричний контроль електроприводу конвеєра.
* Дворівнева SCADA-аналітика (Оперативний пульт FastAPI + Аналітика великих даних у Grafana).
* Збереження часових рядів у гіпертаблиці TimescaleDB.
